CITA PREVIA BOT — لائیو سرچ انٹیگریشن

یہ ورژن آپ کے پرانے Selenium انجن کو Telegram bot کے ساتھ جوڑتا ہے۔ یہ Barcelona/Madrid میں Toma de Huellas کے لیے سرکاری پورٹل کھولتا ہے، کلائنٹ کی معلومات فارم میں بھرتا ہے، دفتر منتخب کرتا ہے، اور اگر پورٹل تاریخ/وقت کی لسٹنگ دکھائے تو اسے Telegram پر بھیجتا ہے۔

اہم حد: CAPTCHA حل یا bypass نہیں ہوتا۔ بوٹ slot منتخب/محفوظ نہیں کرتا، SMS کوڈ نہیں بھرتا، اور آخری بکنگ confirm نہیں کرتا۔ بعض سرکاری پورٹل سیشن CAPTCHA/security checks یا تبدیلیوں کی وجہ سے رک سکتے ہیں۔ اس کوڈ کی Python syntax جانچی گئی ہے، مگر live سرکاری پورٹل پر end-to-end test نہیں ہوا؛ اس لیے حقیقی دستیابی کی ضمانت نہیں۔

1) GitHub میں my-cita-bot کا backup بنائیں۔
2) ZIP extract کریں۔ تمام فائلیں (bot.py, cita_engine.py, requirements.txt, Dockerfile, database.py, README.md, .env.example) اپنے repository کے root میں upload/replace کریں۔
3) Render میں موجود BOT_TOKEN, BOT_URL, ADMIN_ID, DATABASE_URL کو نہ بدلیں۔
4) چونکہ Selenium کو Chromium چاہیے، Render میں نیا Web Service اسی GitHub repository سے بنائیں اور Runtime/Environment میں Docker منتخب کریں۔ موجودہ Python service کو بند نہ کریں جب تک نئی service کامیابی سے چل نہ جائے۔
5) نئی Docker service کا Start Command Dockerfile سے آئے گا؛ کوئی الگ Start Command نہ دیں۔
6) Deploy مکمل ہونے پر Telegram میں /start بھیجیں۔
7) /addprofile چلائیں۔ Client A لکھیں، Barcelona یا Madrid منتخب کریں، پھر کلائنٹ کا نام، دستاویز کی قسم، نمبر، ملک، پیدائش کا سال، فون اور ای میل درج کریں۔
8) /selectclient دبائیں اور Client منتخب کریں۔ سرچ خود شروع ہوگی۔ اگر تاریخ/وقت ملیں تو Telegram پر اطلاع آئے گی۔
9) CAPTCHA یا آخری booking step آئے تو آپ خود سرکاری ویب سائٹ پر مکمل کریں۔

پرانے Client A/B ریکارڈ اگر عام متن (free text) میں ہیں تو وہ نئے profile format میں نہیں ہیں۔ انہیں /addprofile کے ذریعے دوبارہ درج کریں۔

کمانڈز: /addprofile, /selectclient, /viewclients, /deleteclient ID, /status, /health, /cancel.

رازداری: پاسپورٹ/NIE، فون اور ای میل حساس معلومات ہیں۔ صرف کلائنٹ کی اجازت سے درج کریں۔ Telegram اور Render/PostgreSQL اکاؤنٹ محفوظ رکھیں۔
